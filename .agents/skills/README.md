# Upstream skills (vendored)

The `openspec-*` directories in `.agents/skills/` are skills shipped by the
[OpenSpec CLI](https://github.com/Fission-AI/OpenSpec) (`openspec init --tools agents`).
They are kept verbatim and are exempt from the Simplified Technical English
rule in AGENTS.md. Do not edit them by hand; update them through the OpenSpec
CLI.
