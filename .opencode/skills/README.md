# Skills in this directory

- `openspec-*` — skills vendored from the [OpenSpec CLI](https://github.com/Fission-AI/OpenSpec)
  (native OpenCode target: `.opencode/skills/`, the layout produced by
  `openspec init --tools opencode`). They are kept verbatim and are exempt
  from the Simplified Technical English rule in AGENTS.md. Do not edit them
  by hand; update them through the OpenSpec CLI.
- `opencode-kanban-cli` — project-owned skill (board CLI contract for the
  conveyor).
